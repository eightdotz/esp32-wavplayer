# Parts List  
  
# LCSC:  
  
MicroSD Module: JBL JBL-102010052 | 9 pin SD card (one detect pin)  
Display: Wise Vision X096-2864KSWPG01-H30 | SSD1315 Display Driver  
Audio Driver: TI PCM5102APWR  
Voltage Regulator for Display: XC6206P332MR-G  
Buttons: OMRON B3U-1000P | SMD buttons  
Battery Controller: TP4096 | 1a of charging current is fine for this application.  
For higher current charging, try the Consonance CN3791  
  
Audio Jack: KHE PJ-332A-6A  
  
# DigiKey:  
  
USB-C Jack: 2223-UJ20-C-H-G-SMT-1-P16-TRCT-ND | 16 pin USB-C port. 2073-USB4125-GF-ACT-ND is the 6 pin alternative  
CPU: ESP32-C3 (1904-ESP32-C3CT-ND)
